# Metaheuristic Hybridization Classes

Chapter 12 (Raidl & Puchinger) organizes hybrids of metaheuristics with other techniques into four categories: **solution-based** (global hybrids exchange and combine search results between metaheuristics; phase hybrids embed a metaheuristic as local heuristic inside an exact algorithm, e.g. within branch-and-bound), **objective-evaluation-based** (surrogate evaluation, e.g. simulated phylogeny for phylogenetic tree search), **system-based** (hybridized metaheuristics embedded in software infrastructures such as grid computing), and **operator-based** (new operators like gene pool management). The two patterns that carry weight in routing practice: exact solution merging, and relaxation-guided search.

## Core Structure

**Merging solutions exactly.**
- Determining an optimal offspring is NP-hard for 0/1 integer programs with three or more variables per inequality (knapsack, set covering, p-median), so exact merging is a bounded operation, not a free one.
- **CMSA** (construct, merge, solve & adapt): maintain an incumbent sub-instance over a subset of the base component set; each iteration a randomized greedy heuristic generates solutions, their components are added to the sub-instance, and an exact method (MIP solver) finds the best solution of the sub-instance within the time allotment; a disposal mechanism removes seemingly useless components. Applied to minimum common string partition, minimum weighted arborescence, repetition-free longest common subsequence, and the multiple knapsack problem.
- **Rothberg's EA inside branch-and-cut (CPLEX ≥ 10)**: apply the EA as a B&B tree-node heuristic at regular intervals; recombination fixes all variables common to the selected parents and calls the solver on the reduced subproblem; mutation fixes a random subset of one parent and lets the solver set the rest; the number of fixed variables is adaptive.
- **Set-covering merging**: routes of multiple solutions are merged into one solution by solving a set-covering problem over the route pool — the dial-a-ride case (Parragh & Schmid): a set-covering column generation where new reduced-cost columns are generated by VNS on existing routes, LNS improves the current best solution at intervals, and all LNS-generated routes are added to the column pool.
- **Solution integration for multi-depot periodic VRP** (Hachemi et al.): restriction-based operators fix critical characteristics shared by all input solutions; incentive-based operators add incentive terms to the subproblem objective. Restriction-based operators that fix characteristics with consensus across all input solutions win as stand-alone procedures; in cooperative search (UHGS), mixing in incentive-based operators is more fruitful. ^[extracted]

**Guiding the search with relaxation information.**
- Relaxations give bounds and infeasible-but-informative solutions that indicate where good regions of the search space are.
- **LP-relaxation seeded GA for the MKP** (Raidl): solve the LP relaxation, randomized rounding produces a diverse initial population, variables sorted by increasing LP values drive greedy repair (remove items) and greedy improvement (add items in reverse order).
- **Interior point + path relinking/scatter search** (Plateau et al.): early-terminated interior point, rounding plus ascent heuristics generate the initial population.
- **Relaxation-guided VND** (Puchinger & Raidl): for the current incumbent, solve relaxations of each neighborhood, use the relaxation objective values as indicators of potential gain, and search the most promising neighborhoods first; tested on MKP, generally applicable.
- **Pseudo-utility ratios from LP duals** (Chu & Beasley): better indicators of an item's likelihood of being in the optimal integer solution than primal values for the MKP.
- **Lagrangian GA**: prize-collecting Steiner tree (Haouari & Siala) — Lagrangian decomposition of a spanning-tree ILP, volume algorithm solves the dual, edges appearing in intermediate primal trees are kept as a core, initial solutions come from a reduced-cost-based Lagrangian heuristic, and an alternate objective uses reduced costs to focus the search; knapsack-constrained maximum spanning tree (Pirkwieser et al.) — decompose into MST + knapsack, volume algorithm, reduced costs bias initialization/recombination/mutation, best volume-algorithm solution seeds the population, and in most cases the GA proves solutions optimal.
- **Bound-guided crossover** (Dowsland et al.): order-based representation decoded by a construction heuristic that computes bounds for partial solutions; the bound point is the first genotype position whose partial solution bound is worse than the target, and crossover must occur before it, avoiding recombinations that definitely produce worse offspring (pallet loading, 2D packing).
- **Guidance by exact subproblems in evolutionary programming** (Chapter 12): mutation and crossover call an optimization heuristic that exploits subproblems of the current solution.

```
hybrid recipe (routing form):
  pool of solutions from LNS / VNS / GA
  merge exactly (set covering, MIP on fixed-variable subproblem)
  rank neighborhoods by relaxation value (LP, Lagrangian, MST)
  accept by SA on the complex neighborhood   # LNS + SA
```

## Why It Matters

- It is the taxonomy to name a hybrid by: "LNS + SA", "ALNS + MIP repair", "VND guided by LP relaxations", "CMSA", "set-covering merging" all map to classes here, which is how you compare methods across papers.
- It says exact merging is the strong move: fixing consensus variables and calling the solver is stronger than heuristic blending (Hachemi's conclusion), which is the design principle behind the ALNS-for-MIP pattern and the Goel ship-scheduling LNS. ^[inferred]
- Relaxation-guided ordering is the cheapest speedup: it requires only a relaxation solve per neighborhood and directly improves which neighborhood to search.
- It positions branch-and-bound as a metaheuristic *component*, not just an exact method — phase hybrids are where matheuristics live.
- Bound-guided crossover is the transferable trick for permutation-encoded problems: compute a bound per partial solution, cut where the bound breaks.
- The objective-evaluation class warns that surrogate objectives change what is being optimized; any learned/surrogate objective needs validation against the true one. ^[inferred]
